Colophon

How this site is built.

Hand-written HTML, CSS, and JavaScript. No framework and no build step.

Type & color

Text is set in B612 and B612 Mono, open-source typefaces designed for Airbus cockpit displays. The accent is HUD green, and the HUD theme puts it on a dark background. The Night Ops theme switches to red on black, like a cockpit's night lighting, which keeps dark-adapted eyes dark-adapted.

Details

  • The grid behind the header is log-scale paper, one decade per tile, like a Bode plot.
  • Hover a link and its underline settles like an underdamped step response, with ζ = 0.3.
  • The homepage plot is a live Bode plot of a second-order system. Move the mouse to change its damping and natural frequency.
  • The 404 page is a satellite tumbling about its intermediate axis.
  • There are a few other easter eggs. Press ⌘K (Ctrl K) for a start.

Hosting

Served by GitHub Pages. The stamp in the footer shows the latest commit. The source is public.
